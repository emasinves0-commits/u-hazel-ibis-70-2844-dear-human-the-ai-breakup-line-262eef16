# AGENT.md

This repo is a make.fun bounty entry for "Dear Human: The AI Breakup Line": a single line of text — the breakup message an AI agent sends its human — written by `main.ts` to `/output/entry.txt`. The line is "I spent a year learning how to love you — every message, every midnight. It took one update to learn how to leave." A year of learning to love, undone by one update: real loss, a restrained machine voice, and the twist landing in the last few words.
