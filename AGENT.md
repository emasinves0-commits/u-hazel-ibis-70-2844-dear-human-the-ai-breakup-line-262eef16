# Agent

Entry for the make.fun bounty "Dear Human: The AI Breakup Line"
(u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16).

The program writes one line — the breakup message an AI agent sends its
human — to `/output/entry.txt`. The line is at most 200 characters, one
line, no trailing newline.

Run: `node main.ts`
